# 模型 HTTP 状态码回归证据

实际 503 故障的原始日志保留在 [模型演练记录](../2026-10-14-r2-model/command-010.stdout.log)，第 6576 行返回 HTTP 503，第 6786 行抛出中性正文的 `openai.InternalServerError`。原日志的内容指纹见 [修复前清单](before/run.json)。

| 运行 | 源码 | 结果 |
|---|---|---|
| [修复前](before/run.json) | [原分类函数](before/transient.py) | 22 项失败、15 项通过 |
| [修复后](after/run.json) | 结构化状态码优先分类 | 114 项通过，零跳过 |

修复前失败包含中性消息的 408、429 和 5xx 分类，以及 HTTP 4xx 被消息关键词覆盖。真实 SDK 的 HTTP 响应回归覆盖 408、429、500、502、503、504：主模型重试后成功，或重试耗尽后调用备用模型。400、401、403、404、422 各只有一次主模型请求，立即抛出原 SDK 异常。原 SSE 文案、取消、主备配额释放、预算结算和响应恢复测试同时通过。

本地测试使用 `httpx.MockTransport`；本目录记录边界回归，实际多进程演练由主任务继续执行。

每次运行保留 `stdout.log`、`stderr.log`、`tests.xml` 和 `run.json`，清单记录命令、返回码、时间、依赖版本、代码版本及源码内容指纹。
